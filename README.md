# Shahd Student Portfolio

A responsive student portfolio built with HTML5, custom CSS, and Bootstrap 5.3.

## Files
- `index.html` — page structure and content
- `styles.css` — custom colors, spacing, cards, and responsive styling

## Run locally
Open `index.html` in a browser. An internet connection is needed to load Bootstrap from its CDN.

## Customize
Replace the sample biography, projects, and contact details with your real information before submitting.
